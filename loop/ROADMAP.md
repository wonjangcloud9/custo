## Hard rules
1. **Facts must be verified** with WebSearch/WebFetch (official site cutiestreet.asobisystem.com, official X/IG/YouTube, Wikipedia JA, reputable news). Never invent birthdays/heights/video IDs/dates. If unverified → omit or mark "확인 중".
   YouTube video IDs must be verified (e.g. WebFetch `https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=ID&format=json` returns 200).
2. **Images**: do NOT download/commit copyrighted member photos into the repo, and do NOT AI-generate likenesses of the real members. Use official embeds (YouTube iframes / `i.ytimg.com` thumbnails), links to official profile pages, and original illustrated/graphic UI (SVG, gradients, member-color art).
3. **Fan page only — no study/learning content** (user, 2026-11-17: "공부 관련된 건 다 빼자 그저 팬페이지다"). The /japanese/ section, flashcards/SRS/word bookmarks/study dashboard and all '배우기' sections were removed in #69. Do not add language lessons, vocab tables or learning quizzes; fan trivia quizzes (member/song facts) are fine.
4. Each iteration must end with `npm run docs:build` passing AND a Playwright visual check (desktop 1440 + mobile 390) of changed pages via `npm run docs:preview` (port 4173, base `/custo/`). No console errors. Respect `prefers-reduced-motion`.
5. Commit on branch **`fanpage-overhaul`**. One focused commit per iteration, conventional message, with the Co-Authored-By trailer, then **`git push origin fanpage-overhaul`** AND deploy: **`git push origin fanpage-overhaul:main`** (fast-forward only; user request 2026-11-17 — main push = GitHub Pages deploy). Only deploy when build + visual check passed. Afterwards check `gh run list --branch main --limit 1`.
6. Iteration scope: pick the top 1–3 RICE items that fit ~20 min. Small and shipped > big and broken.
7. Keep the site Korean-first UI, with Japanese names/terms alongside.
8. **Every iteration: also look for today's off-channel appearances** (YouTube search sorted by upload date for CUTIE STREET / 큐티스트리트 / きゅーすと, official X, news) and add verified ones to `docs/.vitepress/data/highlights.ts` so the home '오늘의 큐스트' stays current. Verified off-channel YouTube uploads go into the appearance archive via `python3 loop/appearances.py add <kind> <id…>` (official uploaders only; the tool rejects own-channel/unembeddable/deleted videos); same-day ones also go into highlights.ts.
9. **Start every iteration with `node loop/refresh.mjs`** (YouTube RSS of @CUTIE_STREET + @KAWAII_LAB_OFFICIAL → new uploads/MVs/member cuts + durations → rebuild videos.json/feeds.json).
