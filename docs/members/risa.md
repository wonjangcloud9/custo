# 古澤里紗 (후루사와 리사)

<MemberProfile id="risa" />

## 매력 포인트

후루사와 리사는 고등학교 댄스부 시절 **전국대회 우승**을 경험한 실력파 댄서입니다. 옐로 멤버 컬러처럼 무대 어디서나 눈에 띄는 존재감으로 퍼포먼스를 이끌어요.

데뷔 전에는 인플루언서로 활동하며 연애 리얼리티 **「今日、好きになりました。」** 와 **「イマっぽTV」** 에 출연했고, 패션 브랜드 **「Me roir」** 의 디렉터를 맡을 만큼 패션 감각도 남다릅니다. 취미가 **귀여운 옷 만들기(可愛い洋服づくり)** 라는 점도 리사다운 포인트예요.

## 활동 이력

| 시기 | 활동 |
|------|------|
| 고교 시절 | 댄스부에서 전국대회 우승 |
| 데뷔 전 | 인플루언서 활동, 「今日、好きになりました。」·「イマっぽTV」 출연 |
| 데뷔 전 | 패션 브랜드 「Me roir」 디렉터 |
| 2024~ | CUTIE STREET 멤버 |
