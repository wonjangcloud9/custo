# 真鍋凪咲 (마나베 나기사)

<MemberProfile id="nagisa" />

## 매력 포인트

마나베 나기사는 CUTIE STREET 이전에 **연예 활동 경력이 없었던** 멤버입니다. 초등학생부터 중학생까지 **배드민턴**에 몰두했고, 대학 아이돌 카피댄스 서클 **「UNIDOL」** 활동을 거쳐 **KAWAII LAB. MATES** 연수생으로 아이돌의 길에 들어섰어요.

161cm로 그룹에서 가장 키가 크고, 존재감 있는 퍼포먼스가 강점. 댄스와 배드민턴을 좋아하는 활동파입니다.

## 활동 이력

| 시기 | 활동 |
|------|------|
| 초등~중학생 | 배드민턴 |
| 대학 | 아이돌 카피댄스 서클 「UNIDOL」 |
| 데뷔 전 | KAWAII LAB. MATES 연수생 |
| 2024~ | CUTIE STREET 멤버 |

## 이름 읽기 연습

**真鍋凪咲** → まなべ なぎさ (마나베 나기사)

| 한자 | 읽기 | 뜻 |
|------|------|-----|
| 真 | ま | 진짜 |
| 鍋 | なべ | 냄비 |
| 凪 | なぎ | 잔잔한 |
| 咲 | さ | 피다 |
