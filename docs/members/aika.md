# 佐野愛花 (사노 아이카)

<MemberProfile id="aika" />

## 매력 포인트

사노 아이카는 **배우**로 활동하던 중 뮤지컬 출연을 계기로 아이돌에 관심을 갖게 된 멤버입니다. 연기로 다져진 표현력과 **9년 경력의 댄스**가 만나 무대 위에서 풍부한 감정을 보여줘요.

드라마·영화 감상, 먹는 것, 그리고 **야키니쿠 맛집 탐방**을 좋아하는 소탈한 취향도 아이짱의 매력입니다.

## 활동 이력

| 시기 | 활동 |
|------|------|
| 데뷔 전 | 배우로 활동, 뮤지컬 출연 |
| 데뷔 전 | 댄스 경력 9년 |
| 2024~ | CUTIE STREET 멤버 |
