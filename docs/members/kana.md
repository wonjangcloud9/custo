# 板倉可奈 (이타쿠라 카나)

<MemberProfile id="kana" />

## 매력 포인트

이타쿠라 카나는 **10년 넘게 댄스**를 해온 정통 댄서이자, 표현력 있는 퍼포먼스가 강점인 멤버입니다. 어린 시절 **키즈 모델**로 시작해 모델·댄서·인플루언서로 활동했어요.

YouTube에서도 오래 활동해 왔는데, YouTuber 유닛 **「TEENAGERS」**, 채널 **「ハイスクール研究室」**, 그리고 노아와 함께한 **「KANA_NOAチャンネル」**(현재 휴지 중)로 알려져 있습니다. YouTube와 애니메이션 감상을 좋아하는 취향도 카나다운 포인트예요.
